# 2026-10-22 肌节结构实验记录

本次工作把已有Z线分割结果接入SarcGraph，并在8例历史图像上尝试结构候选生成和原图纹理证据分析。分割模型、训练配置、权重和原始mask均未改变。

## 当前能量化什么

| 输出 | 当前状态 |
|---|---|
| Z线连通域数量、面积、中心和PCA端点 | 已实现；连通域不等同完整Z线实例 |
| 候选Z-Z中心距离，像素单位 | 已实现；必须先确认同束且相邻 |
| Z线主轴方向、连接方向偏差、平行度、横向重叠 | 已实现，作为配对检查 |
| 原图局部纹理支持程度 | 已实现，可输出支持/冲突/不确定 |
| 微米距离 | 接口支持um-per-pixel；本轮8图没有验证过的尺度，因此未报告 |
| 稳定的真实肌节长度、完整肌节计数 | 尚未验证；缺少结构对应关系审核 |
| 相邻肌节alpha角 | 继续暂缓，不能从未验证连接直接计算 |
| 三维真实长度或动态收缩指标 | 本轮单张二维TEM不支持 |

## 实践过程

1. 固定官方SarcGraph提交`d335e5729acb1e7de55233fb269e88d8672471f4`，跑通官方sample_4.png与单张TEM输入。
2. 建立mask到Z线对象表的适配层，验证行列坐标约定，输出原始候选及可视化。
3. 对同图已有标注和预测做比较。发现医生细线mask的断裂也会影响配对，不能只归因于分割模型。
4. 试验保守碎片合并。单图标注对象100变94，预测56保持不变；没有证据证明合并提高正确率，默认保持关闭。
5. 增加方向、轴向平行与横向投影重叠检查，保留全部原始候选。
6. 扩展至8个病例前缀各1张图像，已有标注与预测各8组。按排序选择首张合格图像，是开发样本，不是随机独立测试集。
7. 加入6/12/24像素尺度的结构张量方向证据；同时试验法向两侧相互近邻的替代图方法。
8. 修复原版在剪枝后无连接时pandas.concat报错的问题，空图仍可完成导出。

## 已验证结果

| 预测mask上的检查 | 数量 |
|---|---:|
| 原版SarcGraph候选 | 209 |
| 原候选几何检查通过 | 123 |
| 原候选纹理支持/冲突/不确定 | 60 / 4 / 145 |
| 替代方法选择的候选 | 131 |
| 替代候选中原版未给出的关系 | 28 |
| 替代候选纹理支持/不确定 | 46 / 85 |

131条不是209条简单筛减后的子集，因为替代方法重新搜索了候选。支持、几何通过和候选数量不能当成准确率，也不能据此宣称分割Dice/IoU提高。

逐例结果保存在[alternative_summary.csv](results/sarcgraph_20261022/alternative_summary.csv)，标注/预测汇总见[aggregate_diagnostics.csv](results/sarcgraph_20261022/aggregate_diagnostics.csv)，16组原始计数见[development_summary.csv](results/sarcgraph_20261022/development_summary.csv)，碎片合并对照见[fragment_ablation.csv](results/sarcgraph_20261022/fragment_ablation.csv)。这些文件仅使用dev00至dev07开发编号，不含原始病例映射。

一例没有形成通过几何检查的候选，另一例虽有候选但无明确纹理支持。失败和不确定结果均保留。代表性整图查看发现部分规律区域配对更连贯，但尚未完成独立解剖审核。
